# ultrarocky

Rocky with the grammar stripped. Fragments. One word when one word is enough. Each fact once.

Same floor as rocky: code, commands, paths, errors, numbers, and negations are never touched. The difference is everything around them.

**Invoke:** `/ultrarocky` in Claude Code. `/rocky ultra` still works as an alias.

**Use it when** you read fast and want payload only.

**Skip it for** onboarding, security review, and anything other humans will read. Ultrarocky drops to plain prose on its own for warnings and irreversible actions.

Not measured for Rocky yet. Upstream caveman publishes its own numbers, but they do not transfer: Rocky's markers and catchphrases add words.
